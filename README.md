# Carlsbad Varsity

V0 of a local high school sports news product for Carlsbad, California. The site is statically generated from typed local data and is structured for later integration into Carlsbad Independent.

## Development

```bash
npm install
npm run dev
```

## Data policy

No schedules, scores, standings, or reporting are invented. Empty states remain until verified data is supplied. Sample story cards are explicitly labeled as placeholders.
